# War in the world

Prototype de jeu de guerre jouable dans un navigateur, pensé d'abord pour Android.

## Lancer le jeu

Ouvre `index.html` dans un navigateur ou active GitHub Pages dans **Settings → Pages → Deploy from a branch → main → /(root)**.

## Commandes
- Déplacement : joystick tactile ou WASD / flèches
- Viser : glisser sur la zone droite de l'écran ou déplacer la souris
- Tir : bouton FIRE ou clic
- Recharger : bouton RELOAD ou touche R

## Feuille de route
- Prototype solo jouable
- Ennemis contrôlés par l'IA
- Armes, santé, munitions et couverture
- Optimisation Android
- Multijoueur en ligne dans une phase ultérieure

Les graphismes et mécaniques sont un prototype original, pas une copie des ressources propriétaires de Fortnite ou Call of Duty.
