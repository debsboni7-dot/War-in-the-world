# WITW Arsenal — fichiers téléchargeables

Ces fichiers sont de vrais fichiers source ajoutés au dépôt, pas des aperçus graphiques.

- `weapons/rifle-mk7.obj`: maillage OBJ low-poly de prototype, non texturé.
- `equipment/field-pack.obj`: maillage OBJ low-poly de prototype, non texturé.
- `equipment/ammo-crate.obj`: maillage OBJ low-poly de prototype, non texturé.
- `shaders/frontline-contrast.frag`: fragment shader GLSL ES 3.00.
- `shaders/smoke-atmosphere.frag`: fragment shader GLSL ES 3.00.

Les modèles OBJ sont des prototypes géométriques originaux, pas des modèles photoréalistes ni des produits finis PBR. Les shaders sont des sources et doivent être branchés dans un pipeline compatible WebGL2 avant de produire un effet dans le jeu. Les fiches sans lien de fichier disponible ne sont pas encore téléchargeables. Aucun paiement n'est activé dans la boutique.
