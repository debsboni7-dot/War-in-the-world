CONFIGURATION

Paramètres

Réglages graphiques et commandes pour cette version du jeu.

MANETTE PS4 : stick gauche = déplacer, stick droit = caméra, R2 = tirer, L2 = viser, ✕ = sauter, ○ = s’accroupir, □ = recharger, △ = changer d’arme, L1 = gadget, R1 = ramasser, Options = paramètres. Connecte la manette avant ou pendant la partie. Clavier : R recharger, E changer d’arme, F ramasser, C viser. Les armes et munitions sont dispersées sur tout le terrain. Maintiens TIR pour tirer en rafale. La zone rétrécit après la phase de départ.
